## Publicacao recomendada

Para separar da numeracao do Android, publique o instalador pelo GitHub Releases com tag **`windows-v1.1.2`**, nome **`Gold TV Player Windows Edition 1.1.2`**, e anexe `Gold-TV-Player-Setup-1.1.2.exe` ou o ZIP completo.

[Adicionar nova Release Windows](https://github.com/GoldPlay2025/gold-tv-player-updates/releases/new)

**Importante:** uma pasta no repositorio Git nao se converte em pasta de assets na pagina de Releases. O local apropriado para distribuir um instalador binario eh o asset da Release; a pasta `windows/` serve para documentacao e arquivos-fonte.

O manifesto Android `gold_update.json` deve permanecer intocado. O manifesto Windows independente eh `gold_windows_update.json`; atualize-o apenas depois de confirmar que o instalador da Release esta disponivel e validado.
